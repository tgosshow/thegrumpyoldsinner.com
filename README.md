# The Grumpy Old Sinner

A simple home for Silver Fox Broadcasting, featuring Tim Eller and Captin OTTO.

**Truth • Faith • Common Sense**

## Files

- `index.html`: all landing-page text and the microphone illustration.
- `assets/styles.css`: colors, typography, and mobile layout.
- `assets/favicon.svg`: browser-tab icon.
- `.nojekyll`: serves the site as plain static files.
- `404.html`: a standalone page for missing links.

No package installation, JavaScript, database, external fonts, analytics, or paid dependencies. Open `index.html` in a browser to preview it.

## Free GitHub Pages setup

Create the public repository `tgosshow/thegrumpyoldsinner.com`. Add these files to its `main` branch, preserving the `assets` folder. In Settings → Pages, choose **Deploy from a branch**, then **main** and **/(root)**, and Save.

The initial address is `https://tgosshow.github.io/thegrumpyoldsinner.com/`. GitHub Pages is free for public repositories on GitHub Free. The source files are public, so never add passwords or private material.

## Update the site

1. On GitHub, open `index.html` and choose the pencil/edit button.
2. Change the relevant wording while preserving surrounding HTML tags.
3. Choose **Commit changes** and describe the change. Pages republishes automatically once enabled.
4. Check the published page on phone and desktop. Older versions remain in the file history.

To add the first episode, replace the text in the section with `id="latest"` and add a link to the actual episode using `<a href="VERIFIED_EPISODE_URL">Watch the first episode</a>`. Only add confirmed channel links; the starter intentionally makes no claim that episodes are already available.

Colors are defined at the beginning of `assets/styles.css`. Keep the name **Captin OTTO** as supplied. The microphone art is an original inline SVG; no stock-image license or third-party download is needed. This visual direction is a starter, not a claim to reproduce an existing approved logo.

## Existing domain: leave unchanged for now

`thegrumpyoldsinner.com` is the intended future domain. This starter deliberately contains **no CNAME file**, custom-domain redirect, or domain-specific canonical URL. Creating the repository does not change domain registration or DNS.

Before connecting it later, confirm domain ownership and current DNS records, document existing website and email services, verify the domain through GitHub's documented process, and review the specific changes. Preserve mail records and any existing service. Only then configure the Pages custom domain, necessary DNS records, and HTTPS. Do not transfer or repurchase the domain.
